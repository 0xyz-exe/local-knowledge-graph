# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Local Knowledge Graph prioritizes data privacy and local isolation.

- Core features run completely offline on loopback (`127.0.0.1`).
- Documents are processed locally without external telemetry.

If you discover a security vulnerability (such as path traversal in file ingestion or SQLite injection in search queries), please report it responsibly by contacting the maintainer or opening a private GitHub Security Advisory.
